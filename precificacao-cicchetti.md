# Proposta Comercial e Precificação: Site Cicchetti Natal

**Cliente:** Cicchetti Natal (Midway Mall)
**Data:** 07 de Setembro de 2026

## 1. Análise de Complexidade e Escopo Entregue
O projeto consistiu na criação de uma Landing Page/Site Institucional premium (Single Page Application robusta), contendo:
- **Design de Alta Fidelidade (Premium):** Criação de UI/UX baseada em identidade visual complexa (Neo-clássica/Mediterrânea), exigindo grande apuro estético (+800 linhas de CSS customizado, sem uso de templates genéricos).
- **Copywriting Persuasivo & SEO:** Levantamento de briefing, desenvolvimento de copy com gatilhos mentais (AIDA/PAS) e otimização total de SEO On-page (Schema markup, tags completas).
- **Funcionalidades de Frontend Avançadas:** Scrollspy, menu mobile com overlay, modal de galeria dinâmica e formulários com validação e simulação assíncrona.
- **Geração de Imagens AI:** Criação de prompts hiper-realistas para geração de banco de imagens fotográficas próprias para o projeto.

## 2. Estimativa de Esforço (Horas Homem equivalentes)
- **Levantamento e Requisitos (Analista):** 4h
- **Copywriting e SEO Content:** 6h
- **UI/UX Design & Frontend Code (Senior):** 16h
- **Testes, SEO Técnico (JSON-LD) e Ajustes:** 4h
- **Total estimado:** ~30 horas de trabalho altamente especializado.
